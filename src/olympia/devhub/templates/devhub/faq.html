{{ _('Reviews and review times') }}

{{ _('Why is my add-on waiting for manual review?') }} #

{{ _('All submissions go through automated checks that help keep our ecosystem secure. If a submission is flagged for possibly not adhering to our policies, it is added to the manual review queue for a real person to review.') }}

{{ _('How long will a manual review take?') }} #

{{ _('We do not have a fixed turnaround time right now, and we are sorry about that. We are seeing a large influx of new submissions, many of them malicious, so a manual review can take anywhere from a few days to a few weeks.') }}

{% trans url='https://discourse.mozilla.org/t/important-update-addressing-the-long-manual-review-times/148498' %} We cannot give a date for a specific add-on. We wrote about what is happening and what we are doing about it here: Important update: Addressing the long manual review times. {% endtrans %}

{{ _('Will every update I publish go through the manual review process?') }} #

{{ _('Most versions are signed and published automatically, usually within minutes.') }}

{{ _('Only submissions that our checks flag are set aside for a person. A first submission from a new developer is more likely to get that look than the routine updates that follow it.') }}

{{ _('Can I speed my review up?') }} #

{% trans url='https://discourse.mozilla.org/t/help-our-source-code-review-process-add-a-build-for-amo-script/148822' %} The one thing that genuinely helps is including your source code, with a build script the reviewer can run to reproduce your package exactly. This guide walks you through it: Help our source code review process, add a build for AMO script. {% endtrans %}

{{ _('Uploading new versions, resubmitting, or following up repeatedly does not move an add-on up the queue.') }}

{{ _('How do I message my reviewer?') }} #

{% trans %} Use the review tool. On your add-on's page in the Developer Hub, open Manage Status & Versions and add your notes or replies there. {% endtrans %}

{{ _('Reviewers do not monitor Discourse or the support desk, so messages left there will not reach them.') }}

{{ _('My live version is broken, and the fix is stuck in review. What can I do?') }} #

{% trans %} Use the contact form to submit an expedited review request. Include the add-on ID, roughly how many users are affected, and what broke. We will make sure the impact is visible on our side and try to address the review as quickly as possible. {% endtrans %}

{{ _('Is there a way to avoid the public review queue?') }} #

{{ _('If your add-on is only for your own users, you can self-distribute it through the unlisted channel. Most unlisted submissions are signed straight away.') }}

{{ _('Unlisted versions can still be picked up for manual review if our security scanners flag something, and signing waits in that case. Again, that is not a verdict on your add-on.') }}

{{ _('API keys, signing and uploads') }}

{{ _('My API key confirmation email never arrived, or arrived without a link') }} #

{% trans %} Check your spam folder once. If you cannot find an email, wait a few hours and then request a new email. If the second email does not arrive, then contact us using the contact form so we can verify it is you and reset your request. {% endtrans %}

{{ _('The API key request page says: "You have submitted this form too many times recently"') }} #

{{ _('Retrying while the email is slow trips a rate limit. Please stop resubmitting, since each attempt extends the wait. Wait from a few hours up to a day.') }}

{% trans %} If it stays blocked, contact us using the contact form, and we will reset it. {% endtrans %}

{{ _('Accounts and sign-in') }}

{{ _('I cannot sign in to AMO or the Developer Hub') }} #

{% trans url='https://support.mozilla.org' %} For problems with your Mozilla account itself (password, login email, sign-in loops), support.mozilla.org is the right place. {% endtrans %}

{% trans %} If signing in creates a brand-new, empty account, you are most likely signing in with a different email address than the one that owns your add-ons. Contact us privately, and we will help you find the right one. {% endtrans %}

{{ _('Please never post your email address or account details in a public thread.') }}

{{ _('How do I move my add-ons to a new Mozilla account?') }} #

{{ _('You can do it yourself, as long as you can still sign in to the old account.') }}

  1. {{ _('Create the new Mozilla account, verify its email address, and set a display name.') }}
  2. {% trans %} In the Developer Hub, open your add-on's edit page and go to Manage Authors & License. {% endtrans %}
  3. {{ _('Add the new account as an author.') }}
  4. {{ _('Once it shows up, remove the old account.') }}
  5. {{ _('Repeat for each add-on.') }}

{% trans %} If you can no longer sign in to the old account, contact us, and we will help from our side. {% endtrans %}

{{ _('My email address is not allowed to submit add-ons') }} #

{% trans %} Some email domains are blocked from submitting. If you think yours was blocked by mistake, contact us privately with the address and your user ID, and we will look into it. {% endtrans %}

{{ _('Disabled, rejected and appeals') }}

{{ _('My add-on was disabled or rejected. How do I appeal?') }} #

{{ _('You should have received an email explaining the reason and including a link to appeal the decision. Please use that link, and the team will review it.') }}

{% trans %} To send changes or notes for another review, use Manage Status & Versions on your add-on's Developer Hub page. {% endtrans %}

{{ _('I received no email at all') }} #

{% trans %} That is not how it should work, and we are sorry. Contact us, and we will look into what happened with your add-on and why the email did not reach you. {% endtrans %}

{{ _('Resubmitting gives me "Duplicate add-on ID found"') }} #

{{ _('This is expected. While the original add-on is disabled, a new submission with the same ID is blocked, so resubmitting will not bypass it. The appeal is the right path.') }}

{% trans %} IDs that belonged to a deleted add-on cannot be reused either. Use a new ID in your manifest, or contact us if an ID your organization needs is held by a test upload. {% endtrans %}

{{ _('My add-on was hit by a flood of fake one-star reviews') }} #

{% trans %} A sudden burst of near-identical negative reviews looks like a coordinated attack, not real feedback. Report it to us with a link to the add-on and roughly when it started, and we will get it in front of the right people. {% endtrans %}

{{ _('Data collection consent') }}

{{ _('Why do I suddenly need to declare data collection?') }} #

{{ _('It is not new, though it may feel that way. Here is the timeline:') }}

{{ _('When') }} {{ _('What happened') }}
{{ _('October 23, 2025') }} {% trans url='https://blog.mozilla.org/addons/2025/10/23/data-collection-consent-changes-for-new-firefox-extensions/' %} We announced the change: Announcing data collection consent changes for new Firefox extensions {% endtrans %}
{{ _('November 3, 2025') }} {{ _("Every new extension has had to declare its data practices using Firefox's built-in consent system") }}
{{ _('Now') }} {{ _('Established extensions are moving over, so their users see the prompt for the first time in an update') }}

{% trans url=settings.EXTENSION_WORKSHOP_URL + '/documentation/develop/firefox-builtin-data-consent/' %} The developer guide covers how to declare data_collection_permissions in your manifest: Firefox built-in consent for data collection and transmission. {% endtrans %}

{{ _('Does sending technical data, like the browser or OS name, really count?') }} #

{{ _('Yes. Our policies are written with legal experts to match laws worldwide, so the language is very specific. As it stands, sending any information out of the browser, including technical data, triggers the consent requirement.') }}

{% trans url='https://discourse.mozilla.org/c/add-ons/' %} We know some of these cases feel strict. If you have a specific case where the rule produces an outcome that does not make sense, please post it in the Add-ons category on Discourse so we can bring it to our policy discussions. {% endtrans %}

{{ _('Listings, versions and slugs') }}

{{ _('I deleted a version by mistake. Can you restore it?') }} #

{{ _('No, and we are sorry. Deleting a version on AMO is permanent, which is why the deletion flow warns about it twice before you confirm.') }}

{{ _('The version number stays locked afterward, so you cannot re-upload it.') }}

{{ _('I uploaded to the private (unlisted) channel but wanted it public') }} #

{{ _('An existing upload cannot be switched between channels. Upload a new version to the listed channel of the same add-on, and it will go public once it passes review.') }}

{{ _('I hid my add-on and now cannot make it visible again') }} #

{{ _('You can make an add-on visible only when it has an approved version in the listed channel. If your new version is still awaiting review, the option stays unavailable until that review completes.') }}

{{ _('My version is approved, but the public page shows a 404') }} #

{% trans %} Please check if your version is indeed submitted as public and not unlisted. If it is approved and public but you cannot access it, please check your email for an update from us. If you cannot find an update, please contact us. {% endtrans %}

{{ _('The slug I want says it is taken, but its page is a 404') }} #

{{ _('A 404 does not mean the slug is free. Slugs stay reserved by whichever add-on holds them, including add-ons that are unlisted, incomplete, disabled, or deleted.') }}

{{ _("We generally do not take a slug away from another developer's add-on, even one that looks inactive.") }}

{{ _('Users are not getting my new version yet') }} #

{{ _('This is expected. Firefox checks for updates periodically, so it usually takes around 24 to 48 hours for an approved version to reach users.') }}

{{ _('My stats dropped to zero or show "No data available"') }} #

{{ _('Stats are processed with a delay, so a new add-on can show no data for its first days. A sudden drop to zero is usually a reporting issue, not your users disappearing.') }}

{% trans url='https://discourse.mozilla.org/c/add-ons/' %} If it lasts, post in Discourse with a link to the add-on, and we will check for a known issue. {% endtrans %}
