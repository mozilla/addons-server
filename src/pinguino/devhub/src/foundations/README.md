# foundations

Web foundations the DevHub builds on: acorn registration, design tokens, layout primitives (`layout/`), and shared badges (`badges/`). These live inside `devhub` for now, but are meant to become the reusable layer shared across future pinguino product areas — the layout primitives in particular are candidates to graduate into acorn as `moz-*` components. See the [devhub README](../../README.md).
